- Honkai Star Rail Eidolons

General Workflow:

- Have a component in charge of calculating the percentages of the slots in
  the canvas.
- Cache those used so we don't have to recalculate if the user changes their
  mind and wants to revert.
- We'll have to generate multiple variations of the sidebar, since each layout
  family (uniform, full/small, shards) has a different set of configuration
  parameters. Some are universal though, such as width, height, and colors.
